# مختبر المسند الرقمي

تطبيق Streamlit عربي لدراسة نقوش جنوب الجزيرة العربية (الإصدار 3.0). أعيد تنظيم الواجهة إلى أربع مساحات عمل منفصلة: **عين المسند** لرفع الصور والتقاطها، **المساعد الإبيغرافي** للمقارنة والتحليل، **البوابة العالمية** للبحث والمدونات والتخزين الميداني، و**الإعدادات المتقدمة** للمزودين والخصوصية.

## التشغيل

```bash
python -m venv .venv
. .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

افتح **الإعدادات ← المعالج الذكي** لإضافة مزود، أو استخدم **وضع المحاكاة** لتجربة الواجهة من دون مفتاح. بيانات SQLite محلية لكل نسخة تشغيل ولا تدخل ملفات قواعد البيانات والمفاتيح في Git.

## الخصوصية وحدود التخزين الميداني

- مفاتيح API موجودة في ذاكرة جلسة Streamlit فقط، ولا تُحفظ في SQLite. قفل PIN يمنع الاستخدام من الواجهة ويحوّل المفاتيح الرئيسية إلى صيغة مشفّرة محلياً، لكنه لا يضمن إزالة جميع النسخ من الذاكرة ولا يُعد بديلاً عن تأمين الخادم.
- صفوف الأرشيف وقائمة الانتظار مرتبطة بمعرّف عشوائي خاص بالجلسة. قاعدة البيانات نفسها محلية على الخادم.
- التخزين الميداني يعني حفظ الطلب والصورة في قاعدة SQLite المحلية التابعة للتطبيق، ثم مزامنتهما عند عودة اتصال الخادم ومفتاح Gemini. ليس وضع PWA/متصفحاً يعمل دون اتصال بالخادم.
- وضع المحاكاة لا يرسل النص أو الصورة إلى مزود خارجي، ومخرجاته موسومة بأنها توضيحية وليست تحليلاً أثرياً.

## الدقة العلمية وحدود التنفيذ

- المداخل المدمجة رؤوس استرشادية غير متحققة، وليست نقولاً أو إحالات موثقة. راجع السجل الأصلي قبل الاستشهاد. نتائج النماذج مسودات، ولا يمكن ضمان صحة مراجعها أو قراءاتها آلياً؛ راجعها مع مختص.
- لا يجلب المساعد مراجع من DASI أو CSAI أثناء التوليد. يقتصر البحث المحلي على الفهرس والأرشيف المحليين.
- تجرى طلبات النماذج وفحص المصادر وجلب النماذج ومزامنة القائمة في خيوط خلفية، وتظهر النتيجة أثناء بقاء جلسة Streamlit نشطة. قد تستمر الطلبات التي بدأت بالفعل عند قفل الجلسة أو إغلاق الصفحة؛ القفل لا يلغيها. يمنع حذف البيانات أو مسح المفاتيح من الواجهة أثناء وجود مهام نشطة.
- المزامنة التلقائية تُجدول أثناء عرض قسم التخزين الميداني، ولا تعمل كخدمة مستقلة بعد انتهاء الجلسة. إذا انقطع التنفيذ وبقي عنصر بحالة المعالجة، تتاح استعادته يدوياً؛ تأكد أولاً من توقف التنفيذ السابق لتجنب تكرار الإرسال. معرّف الجلسة مؤقت، فلا تضمن إعادة تحميل الصفحة استعادة الوصول لصفوفها.
- عرض PDF الحالي لا يدعم العربية أو الأحرف غير ASCII؛ استخدم Word أو Markdown للنصوص متعددة اللغات. يمكن أن تكون أسماء النماذج المبدئية قد تغيرت لدى المزود؛ تحقق من توفرها قبل الاعتماد عليها.
- وضع المحاكاة يخص المساعد فقط؛ البحث الخارجي ومزامنة الطابور وفحص المصادر وظائف مستقلة ويمكنها الاتصال بالشبكة إذا طلبت تشغيلها.
- لا يعتمد عزل الجلسة على مصادقة مستخدمين، ولا يحمي قاعدة البيانات ممن يملك وصولاً إلى خادم التطبيق. استخدم خدمة موثوقة ومحمية، ولا تدخل عنوان مزود مخصصاً غير موثوق لأن المفتاح سيُرسل إليه.

## الاختبارات

```bash
pip install pytest
pytest -q
```

تستخدم الاختبارات طلبات شبكة وهمية؛ ولا تتحقق من عمل مفاتيح حقيقية أو توفر خدمات المزودين.
